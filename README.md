### Windows Setup Guide

- Init .venv
```bash
python -m venv .venv
```
- Activate venv
```bash
.\.venv\Scripts\Activate.ps1
```
- Install packages
```bash
pip install -r requirements.txt
```
- Run program
```bash
python main.py
```
